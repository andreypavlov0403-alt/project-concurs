# Исправления и оптимизация — 9 ноября 2026

## Исправления по возрастанию критичности

| Приоритет | Замечание | Решение |
| --- | --- | --- |
| P3 | HEAD раскрывал метаданные закрытых файлов | Единая проверка статических путей через send_head для GET и HEAD, без тела ответа на HEAD |
| P2 | Выход исчезал на мобильном экране | Добавлена отдельная мобильная кнопка с тем же обработчиком |
| P2 | SQLite-соединения оставались открытыми | Явное закрытие через contextlib.closing, границы транзакций сохранены |
| P2 | Истечение сессии оставляло неработающий интерфейс | Обработка HTTP 401 сбрасывает данные и пользователя, показывает вход |
| P2 | Обновление рейтинга не читало сервер | Загрузка состояния с сервера и обновление всех представлений |
| P2 | Импорт и восстановление перекрывали другие операции | Общая блокировка действует до чтения файла и снимается в finally |
| P1 | Неудачная запись оставалась в таблице | Подтверждённое состояние отделено от отправляемого; при неопределённом результате требуется синхронизация |
| P1 | CSV молча отбрасывал столбцы и менял баллы | Проверка количества полей и символов после кавычки, сообщения с номером строки |

При потере ответа запись могла уже попасть в БД. Клиент перечитывает сервер, не отправляет запрос автоматически повторно и до восстановления связи блокирует сохранение и экспорт. В форме редактирования введённые значения сохраняются для повторного решения пользователя.

## Оптимизация

- Рейтинг вычисляется один раз для подтверждённого состояния и используется повторно при переходах и экспорте.
- Статистика рассчитывается одним проходом и кешируется.
- Для сортировки имён повторно используется Intl.Collator; удалена лишняя копия массива.
- Поиск использует подготовленные строки, участники отображаются страницами по 100.
- Импорт, содержащий только совпадения, не отправляет лишнюю запись и не увеличивает версию.
- При старте не пересчитываются хеши уже существующих пользователей. Параметры хеширования не ослаблены.

Микрозамер на 10 000 синтетических участников, медиана 21 запуска после 5 прогревов:

| Операция | До | После |
| --- | --- | --- |
| Сортировка и места | 10,580 мс | 5,443 мс |
| Статистика и распределение | 0,672 мс | 0,366 мс |

Это измерение вычислительных функций в среде разработки, без сети, отрисовки браузера и кеширования. Оно не означает двукратного ускорения всего приложения. Повторный замер: node tests/benchmark.cjs. Результаты на других компьютерах будут отличаться.

## Проверки

- Python: 5 интеграционных тестов, успешное завершение на Windows/Python 3.14, включая удаление временной БД.
- JavaScript core: CSV, кавычки, разделители, места, нулевой балл, статистика и безопасный экспорт.
- JavaScript UI: обычное добавление, ошибка сети, запрет экспорта до синхронизации, потеря ответа после записи, конфликт версий, обновление с сервера, блокировка операций при чтении файла, повреждённый CSV, повторный импорт, восстановление, сессии и роли.
- Оптимизация UI: пагинация, поиск со сбросом страницы, переиспользование рейтинга и сброс кеша после изменения данных.
- JavaScript-проверки выполнены во встроенном Node, поскольку отдельная команда node отсутствует в PATH этой среды.
- Визуальная браузерная приёмка и печать пока не подтверждены; DOM-стенд не заменяет эти проверки.

Схема существующей БД не изменялась. Рабочая база не использовалась при тестировании. План дальнейших работ: ROADMAP.md.

- Учительский ключ генерируется из криптографически случайных данных, показывается в консоли один раз. В SQLite хранится только SHA-256-хеш. Замена: python server.py --rotate-teacher-key.
- Пароли PBKDF2 с солью. Логины без учёта регистра; валидация длины паролей и логинов; ограничение 20 попыток входа/регистрации в минуту с адреса.
- Миграция добавляет disabled к пользователям и таблицу settings. При миграции отключаются публичные демонстрационные пароли; пользователи с другими паролями сохраняются. Мероприятие не меняется.
- Автотесты: 10 серверных сценариев, core, theme и UI. Проверена миграция старой схемы с сохранением мероприятия и действующего персонального аккаунта.
- Визуальная проверка через computer-use остановлена средой: текущий Windows-браузер не поддерживает необходимый контроль URL. Внешний вид и печать визуально не подтверждены.
