# SchoolFlow

**Формат:** локальное веб-приложение, прототип направления «Создай сервис».

**Проблема.** После школьного конкурса организатор вручную сводит списки участников, сортирует результаты и готовит отчёт. В таблицах легко перепутать непроверенную работу с нулевым баллом, потерять изменения или неправильно назначить места при равенстве результатов.

**Целевая аудитория:** учителя и организаторы олимпиад, ученики, которым нужно видеть рейтинг.

**Цель:** превратить список участников и баллы в проверенный итоговый протокол с минимальной ручной обработкой.

**Сценарий.** Учитель входит, настраивает мероприятие, загружает CSV, уточняет результаты и получает автоматически рассчитанный рейтинг. На обзоре видны число участников, число проверенных работ, средний и лучший баллы, распределение результатов. Ученик входит под отдельной ролью и просматривает данные без возможности менять их. Сервер проверяет права независимо от видимости кнопок.

**Обработка.** CSV → разбор заголовков и кавычек → проверка записей → исключение совпадений имени и класса → подтверждение → SQLite → рейтинг и статистика → CSV, JSON или печатный протокол. Некорректный пакет не записывается частично. Пустой балл отличается от нулевого. У равных баллов одинаковые места.

**Хранение.** SQLite сохраняет мероприятие после остановки сервера. JSON позволяет переносить и восстанавливать данные. Проверка версии предупреждает о конфликтующих изменениях из разных окон.

**Технологии.** Python 3.10+, стандартные модули HTTP/SQLite, HTML, CSS, JavaScript. Для запуска не требуются сторонние библиотеки. Пароли хешируются PBKDF2, авторизация использует серверную сессию и HttpOnly-cookie. Локальный сервер открывает только необходимые статические файлы.

**Результат.** Рабочий локальный прототип с пакетным импортом, редактированием, поиском, рейтингом, диаграммой, экспортом и восстановлением. Ускорение работы предполагается за счёт автоматизации; измерений на реальной школе пока нет.

**Проверки.** Пройдены автоматические тесты данных, API и привязок интерфейса. Визуальную проверку в пользовательском браузере и запись видео необходимо провести перед подачей.

**Ограничения.** Одно мероприятие и регистрация пользователей; учителя создаются по ключу приглашения. Нет персональной видимости результатов, генерации грамот и публичного хостинга. PDF сохраняется через диалог печати браузера. Следующий этап — несколько мероприятий и управляемые учётные записи.
