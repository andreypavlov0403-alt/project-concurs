# SchoolFlow — рабочий локальный прототип

SchoolFlow помогает учителю провести школьную олимпиаду или конкурс: загрузить участников, внести баллы, автоматически получить рейтинг и выгрузить итоговый протокол. Целевая аудитория — учителя и организаторы школьных мероприятий; ученик получает доступ к просмотру общего рейтинга.

## Запуск

Требуется Python 3.10 или новее. Дополнительных Python-пакетов и доступа к интернету не требуется.

1. Распакуйте архив целиком.
2. В Windows откройте `start.bat` либо выполните в папке проекта `python server.py` (на некоторых системах — `python3 server.py`).
3. Откройте http://localhost:8000 в современном браузере.
4. Откройте «Регистрация» и создайте аккаунт. Без ключа создаётся ученик; для учителя раскройте «Регистрируетесь как учитель?» и введите ключ приглашения.
5. После регистрации войдите с выбранными логином и паролем.

При первом запуске обновлённого сервера в консоли появится строка `Teacher registration key ... SF-T-...`. Сохраните ключ и передавайте его только будущим учителям. Это общий многоразовый ключ. В базе хранится только его SHA-256-хеш; ключ не отдаётся через API и не включён в файлы сайта. При следующих запусках ключ не показывается заново. Если ключ утерян или раскрыт, остановите сервер и в папке проекта выполните:

```sh
python server.py --rotate-teacher-key
```

Команда покажет новый ключ и завершится. Затем снова запустите сервер. Старый ключ перестаёт разрешать регистрацию, уже созданные аккаунты продолжают работать.

Логин: 3–32 символа (латиница, цифры, точка, дефис, подчёркивание), без учёта регистра. Пароль: 10–128 символов. Ключ нужен только при создании учительского аккаунта, при обычном входе вводить его не требуется. За минуту с одного адреса разрешено до 20 совокупных попыток входа и регистрации.

**Обновление старой базы:** при первом запуске добавляются настройки и признак отключённого аккаунта. Старые публичные аккаунты `teacher / teacher123` и `student / student123` отключаются, если пароли совпадают с демонстрационными. Они больше не подходят для входа; создайте свои аккаунты. Пользователи с изменёнными паролями сохраняются, данные мероприятия не заменяются. Перед обновлением существующей установки сохраните резервную копию.

Все зарегистрированные пользователи пока работают с одним мероприятием: ученики просматривают, учителя редактируют. Регистрация ещё не создаёт изолированный личный кабинет или отдельное мероприятие.

Открывать `index.html` двойным щелчком не нужно: интерфейс использует API сервера. Если порт занят: `python server.py --port 8001`, затем откройте http://localhost:8001.

При первом запуске создаётся `schoolflow.sqlite3` с примером мероприятия. При последующих запусках используются сохранённые данные. Закрытие окна сервера останавливает приложение, но не удаляет базу. Сессии действуют до восьми часов и сбрасываются при перезапуске.

## Использование

- На вкладке «Обзор» измените название и максимум баллов, нажмите «Сохранить настройки».
- На вкладке «Участники» добавляйте, редактируйте и удаляйте записи; поиск работает по всему списку по имени и классу. Список отображается страницами по 100 участников; экспорт содержит все записи.
- Пустое поле баллов означает «Ожидает». Число `0` — проверенная работа с нулевым результатом.
- В рейтинг попадают только проверенные работы. При равенстве баллов места совпадают: `1, 1, 3`. Среднее и диаграмма также учитывают только проверенные работы.
- Диаграмма показывает интервалы `[0,25)`, `[25,50)`, `[50,75)`, `[75,100]` процентов от максимума.
- «Отчёты и экспорт»: CSV для таблиц; JSON для полного восстановления; печать рейтинга и сохранение PDF средствами браузера. Печатный протокол содержит название мероприятия и максимальный балл.
- CSV содержит всех участников, включая ожидающих без места и балла. JSON содержит все данные мероприятия.

## Пакетная обработка

CSV кодируется в UTF-8 (допускается BOM). Разделитель — запятая, точка с запятой или табуляция; один разделитель на весь файл. Заголовки: `name,class,score` либо `ФИО;Класс;Баллы`. Без заголовка требуются ровно три столбца. С заголовком количество полей каждой записи должно совпадать с числом столбцов заголовка; дополнительные именованные столбцы допустимы. Для пустого балла оставьте пустое третье поле с разделителем. Лишние или пропущенные поля отклоняются с номером строки. Пустой балл оставляет работу непроверенной. Десятичная запятая допустима при разделителе `;` или внутри кавычек.

Примеры находятся в `data/sample.csv`, `data/sample.json` и `data/participants-120.csv`. Последний файл позволяет показать пакетную обработку 120 участников. Перед импортом приложение сообщает число новых записей и совпадений имени и класса; совпадения пропускаются, баллы существующих участников не перезаписываются. Если хотя бы одна запись некорректна, импорт отменяется целиком. Предел: 10 000 участников, файл до 5 МБ.

Для переноса мероприятия скачайте JSON, затем на другом запуске выберите «Восстановить JSON». Восстановление заменяет текущее мероприятие после подтверждения; сначала сохраните его копию. Сервер проверяет каждую запись. Исходные данные старого прототипа из localStorage автоматически не читаются: их можно перенести через JSON.

## Архитектура и исправления

- `server.py`: HTTP API, SQLite, проверка данных, пароли PBKDF2, серверные сессии HttpOnly/SameSite и проверка роли на записи.
- `js/core.js`: независимые операции CSV, рейтинга и безопасного экспорта в таблицы.
- `js/main.js`: интерфейс, API, импорт/восстановление, статистика.
- `css/style.css`: адаптивный интерфейс и печатный вид; внешние шрифты не требуются.
- Версия данных предотвращает незаметную перезапись изменений из другой вкладки. При конфликте интерфейс загружает актуальное состояние и сообщает об ошибке.
- Исправлены смешивание нулевого балла с отсутствием проверки, неверные места при ничьей, отсутствие восстановления JSON, разбор CSV с десятичной запятой, молчаливое отбрасывание ошибок импорта и внедрение HTML через идентификаторы.
- CSV экранирует формулы для безопасного открытия в табличных редакторах. При обратном импорте таких имён защитный апостроф может остаться; для точного переноса используйте JSON.

## Проверки

```sh
python tests/server_test.py
node tests/core.test.cjs
node tests/ui.test.cjs
node tests/theme.test.cjs
```

Node.js нужен только для JavaScript-тестов. Python-тест использует временную базу. Проверены вход/выход, запрет записи ученику, серверная валидация, конфликт версий, закрытый доступ к базе и исходникам, нулевые/пустые баллы, места при равенстве, CSV с кавычками и BOM, а также привязки интерфейса (запуск, добавление, поиск, рейтинг) через имитацию DOM. Эти проверки проходят.

Полноценная визуальная проверка в браузере среды разработки не завершена: локальный Chromium блокируется ограничением создания сокетов, а отдельный облачный браузер не имеет доступа к этому локальному серверу. Перед записью презентации проверьте внешний вид в своём браузере, включая мобильную ширину и печать.

## Связь с положением

Прототип развивает направление кейса 3 «Создай сервис»: разграничение учитель/ученик, хранение в БД, визуализация, экспорт отчётов и PDF через печать браузера. Для кейса 2 также реализованы пакетная загрузка и автоматический рейтинг. Это техническое сопоставление, а не гарантия оценки жюри.

В положении (приложение 4) для подачи указаны код, краткая документация на 1–2 страницы, примеры данных, пример результата и видеопрезентация до семи минут. В архиве есть краткое описание `PROJECT.md`, примеры и сценарий демонстрации `DEMO.md`; видеопрезентацию необходимо записать отдельно.

## Границы прототипа

Одно мероприятие, зарегистрированные пользователи, общие данные и рейтинг. Нет личных кабинетов с индивидуальной видимостью, массовой выдачи грамот, нескольких мероприятий или автоматической проверки заданий. Сервер привязан к localhost и предназначен для локальной демонстрации. Публичное развёртывание требует промышленного веб-сервера, HTTPS, управления пользователями и настройки защиты; встроенный HTTP-сервер для этого не предназначен. Не вводите реальные персональные данные для конкурсной демонстрации.

## Обновление надёжности и производительности

Кнопка «Обновить» рейтинга загружает данные с сервера. При истечении сессии приложение возвращается ко входу. На мобильном экране доступна отдельная кнопка выхода.

При ошибке сохранения в таблицах остаются последние подтверждённые данные. Если сервер недоступен и результат записи неизвестен, приложение блокирует сохранение и экспорт до успешной синхронизации. Используйте кнопку «Синхронизировать»; автоматического повторения записи нет. Импорт и восстановление блокируют параллельные изменения уже во время чтения файла.

Подробности исправлений, проверок и замеров: [CHANGES.md](CHANGES.md). План дальнейшего развития с критериями приёмки: [ROADMAP.md](ROADMAP.md). Для воспроизводимого микрозамера используйте `node tests/benchmark.cjs`.

## Обновлённый интерфейс и тема

Переключатель светлой/ночной темы доступен на экране входа и в шапке приложения. При первом открытии учитывается тема системы; ручной выбор запоминается в этом браузере и синхронизируется между вкладками. Если браузер запрещает localStorage, переключение работает в текущей вкладке. Печатный протокол всегда светлый. Изменены типографика, таблицы, карточки и мобильная навигация.


## Модульный интерфейс и управление составом

Архитектура и подробные сценарии: [ARCHITECTURE.md](ARCHITECTURE.md).

- Выбранный раздел сохраняется в URL, F5 больше не возвращает на обзор. Доступны кнопки истории браузера.
- На мониторе ученика — таймер, личный балл, место и отрывы. Рейтинг содержит баллы задач и выделяет свою строку. Обновление: каждые 15 секунд в видимом разделе.
- Учитель управляет составом через «Активные ученики», «Ожидают подтверждения» и «Настройка доступов». Можно подтверждать, замораживать, возобновлять доступ, отвязывать аккаунт без удаления работы, связывать аккаунт с импортированной записью.
- «Пригласить учеников»: класс и необязательный список email или CSV с одним столбцом email. До 100 адресов. Полученные одноразовые ссылки действуют 7 дней; письма не отправляются. Сохраните ссылки сразу после создания.
- В «Мероприятие» настраиваются предмет, описание, школа, расписание, статус, задачи и правила видимости. Задачи: `код | название | максимум`, по одной в строке. До 20. Старые общие баллы сохраняются, пока не введены баллы задач.
- В «Мой аккаунт» доступны имя, школа, класс, email, уведомления об обновлении результатов и смена пароля. После смены пароля все сеансы завершаются.
- Администратор назначается локально: `python server.py --make-admin login` (аккаунт должен существовать). Затем запустите сервер обычным способом. У администратора доступны роли и глобальная блокировка аккаунтов; последнего администратора отключить нельзя.

Мероприятие по-прежнему одно. JSON переносит настройки и результаты; для переноса аккаунтов, связей и инвайтов нужна резервная копия всей SQLite-базы. Email в приглашении сопоставляется с профилем, но владение адресом не проверяется. Расписание показывает время, но система пока не принимает решения задач и не ограничивает отправку ответов.
