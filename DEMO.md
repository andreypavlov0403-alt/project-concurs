# Сценарий демонстрации — около 5–6 минут

1. **0:00–0:40.** SchoolFlow, локальное веб-приложение. Проблема: учитель вручную обрабатывает результаты конкурсов. Цель: пакетный ввод → автоматический рейтинг → готовый отчёт.
2. **0:40–1:10.** Заранее зарегистрировать учительский аккаунт с ключом из консоли сервера. Войти под ним. Показать обзор, изменить название мероприятия, сохранить настройки.
3. **1:10–2:00.** Импортировать `data/participants-120.csv`. Подтвердить пакет. Показать поиск по классу; повторить импорт и показать пропуск совпадений.
4. **2:00–2:50.** Добавить участника с пустым баллом: он ожидает проверки и не занимает место. Изменить его балл на 0: работа проверена. Выставить двум участникам равные высокие баллы и показать одинаковые места.
5. **2:50–3:40.** Показать среднее, диаграмму и рейтинг. Скачать CSV и открыть в табличном редакторе. Показать печатный протокол и сохранение PDF.
6. **3:40–4:20.** Скачать JSON. Изменить запись, восстановить JSON и показать возвращение данных. Выйти.
7. **4:20–5:00.** Зарегистрировать ученический аккаунт без ключа и войти под ним. Показать просмотр без кнопок изменения; пояснить, что сервер также запрещает запись.
8. **5:00–5:40.** Кратко: Python + SQLite + JavaScript, данные сохраняются после остановки, проверка конфликтов версий. Ограничения: одно мероприятие, общие данные, локальная работа. Польза: больше не нужно вручную пересортировывать списки и готовить каждый отчёт.

Перед записью: запустить приложение, проверить печать и внешнее оформление на своём компьютере. Использовать только вымышленные данные. Видео пока не входит в комплект — его нужно записать отдельно.
